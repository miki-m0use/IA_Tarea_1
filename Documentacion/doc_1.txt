El dataset escogido sera el de los hongos “mushroom” seleccionado de la página: 
https://archive.ics.uci.edu/dataset/73/mushroom

el data set cuenta con 8124 filas y 23 columnas, de las cuales se eliminaran algunas,  
dado que el dataset incluye una información adicional y que en esta se menciona que: 

* Información adicional
* Este conjunto de datos incluye descripciones de muestras hipotéticas correspondientes a 23 especies de hongos con branquias de 
* la familia Agaricus y Lepiota (págs. 500-525).  Cada especie se identifica como definitivamente comestible, definitivamente venenosa o 
* de comestibilidad desconocida y no se recomienda.  Esta última clase se combinó con la venenosa. 
* La Guía establece claramente que no existe una regla simple para determinar la comestibilidad de un hongo; no existe una regla como 
* "folletos tres, déjalo ser" para el roble venenoso y la hiedra.

notamos que lo importante de la categorizacion de los hongos es que esta sea definida como “Comestible” o “Venenosos” por lo que iremos eliminando columnas las cuales reconocemos como importantes para reconocer hongos con caracteristicas no importantes para reconocer hongos comestibles o venenosos.
